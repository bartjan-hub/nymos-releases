# Nymos

**Nymos renames your files based on what's inside them.**

Drop in PDFs, images, Word documents, spreadsheets or presentations, and Nymos
reads each one and suggests a clear, consistent filename. You review every
suggestion before anything is renamed — nothing changes on disk without your
say-so.

## Download

**[Download the latest version →](../../releases/latest)**

Requires macOS 14 (Sonoma) or later. Apple silicon and Intel.

## What it does

- Reads the actual content of a file, not just its name
- Names each file in its own language, or a language you pick
- Templates for recurring document types (invoices, receipts, contracts)
- Watch a folder and get suggestions as files arrive
- Full rename history with one-click undo

Nymos is free to try — no card needed. Subscriptions are available in the app
and at [nymos.io](https://nymos.io).

## Privacy

Nymos reads only the files you give it. Document text is never stored or
logged. It never scans your disk on its own.
